# Morgan Virtual Board Member - Phase Brief

## Purpose
Morgan is an AI-powered "eighth board member" that broadens perspective and improves board discussion quality.

## Capability Ladder

### Phase 1 - Bring Morgan to Life
Goal: establish a practical OpenAI-based foundation and working demo baseline.
Success criteria:
- Local app can run end-to-end with OpenAI API connectivity.
- Consent, redaction, and retention defaults are enforced.
- Core models and orchestration settings are configurable.

### Phase 2 - Passive Participant
Goal: Morgan listens continuously and only responds when invited.
Success criteria:
- Meeting cockpit ingests audio and produces live transcript updates.
- Morgan does not interrupt without explicit invitation.
- Invited response includes rationale and alternative perspective.

### Phase 3 - Reactive Contributor
Goal: Morgan raises a virtual hand when it detects meaningful patterns.
Success criteria:
- Model-driven monitor identifies contradictions, missed connections, or risks.
- UI displays subtle raise-hand cue and concise recommendation.
- Intervention cooldown prevents repetitive prompts.

### Phase 4 - Morgan and Friends
Goal: add multiple fixed-perspective board member agents.
Success criteria:
- Eight default personas are available (e.g. Gen Z, near-retirement, public sector).
- Board can direct questions to specific personas in real time.
- Persona studio supports interview-based profile synthesis (values and decision style).

### Phase 5 - North Star Shadow Board
Goal: run a pre-meeting, multi-agent simulated board discussion.
Success criteria:
- Agenda/topics can be submitted and executed against all personas.
- Output includes consensus, dissent, risk flags, and recommendations.
- Result is reviewable as a provocation artifact before the real meeting.

## Non-Functional Defaults
- Local-first operation with minimal retention by default.
- No raw audio persistence by default.
- Redaction enabled by default for persisted transcript text.
- Client-facing experience with presentation-ready UI states.
