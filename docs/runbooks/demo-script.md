# Morgan Demo Script

## 1. Kickoff
1. Open `/meeting` and enable consent.
2. Choose `BlackHole 2ch` or `Microsoft Teams Audio` input if available.
3. Start meeting capture and confirm live transcript appears.

## 2. Passive Morgan
1. Discuss a sample agenda topic for 1-2 minutes.
2. Confirm Morgan remains silent in passive mode.
3. Click `Invite Morgan` and review structured response.

## 3. Reactive Morgan
1. Continue discussion with conflicting statements.
2. Watch for raise-hand cue and suggestion card.
3. Review intervention history panel.

## 4. Persona Studio
1. Go to `/personas`.
2. Run guided interview to create a board-member-style persona.
3. Save and verify persona appears in list.

## 5. Shadow Board
1. Go to `/shadow-board`.
2. Submit agenda and topics.
3. Run 8-persona simulation.
4. Review synthesis report and dissent points.

## 6. Presenter Notes
- Emphasize governance defaults: consent, redaction, no raw audio saves.
- Emphasize values + decision style capture, not identity cloning.
